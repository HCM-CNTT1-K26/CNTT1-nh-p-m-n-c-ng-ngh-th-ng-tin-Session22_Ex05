## 2. Quy Trình 3 Bước Tra Cứu Tự Phục Vụ

1. **Googling:** Trích xuất đoạn lỗi trọng tâm (Error Message), loại bỏ thông tin cá nhân hoặc dự án để tra cứu trên Google (tập trung vào Stack Overflow, GitHub Issues).
2. **Community Search:** Tìm kiếm từ khóa lỗi trên thanh công cụ của kênh chat nội bộ hoặc tab Issues thuộc bộ mã nguồn/thư viện đang sử dụng.
3. **AI Translation & Prompting:** Dán log lỗi kèm thông tin môi trường vào AI để dịch nghĩa, phân tích nguyên nhân gốc rễ và lấy hướng dẫn/lệnh khắc phục nhanh.
